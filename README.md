# Athkar App - تطبيق أذكار الصباح والمساء المتجددة يومياً

تطبيق فلاتر متكامل ومصمم بعناية لقراءة وتتبع أذكار الصباح والمساء مع خاصية التجدد التلقائي اليومي للعدادات.

## المميزات الرئيسية:
- **تجدد يومي تلقائي (Daily Auto-Renewal):** تتصفر العدادات تلقائياً مع بداية كل يوم جديد بدون أي تدخل يدوي.
- **تتبع التتابع اليومي (Streak Tracking):** يحسب التطبيق عدد الأيام المتتالية التي تحافظ فيها على أذكارك لتشجيعك.
- **حفظ فوري ومستمر:** يتم حفظ تقدم كل ذكر بشكل فوري عبر `SharedPreferences`.
- **واجهة عصرية بتصميم داكن وفخم:** تدعم الوضع الليلي ومريحة للعين في الصباح والمساء.
- **عداد تفاعلي سريع:** زر تفاعلي لكل ذكر يوضح عدد المرات المتبقية ونسبة الإنجاز.
- **نصوص موثقة ومشكلة بالكامل:** أذكار الصباح والمساء من صحيح السنة النبوية مع توضيح فضل كل ذكر.
- **دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL):** متوافق 100% مع الاتجاه العربي.

## طريقة التشغيل:
```bash
flutter pub get
flutter run
```
